# Dataset Information

- Name: NEU Surface Defect Dataset
- Source: https://universe.roboflow.com/neudefectdetection/neu-surface-defect-pohqa
- Format used: YOLOv8
- Classes: crazing, inclusion, patches, pitted_surface,
  rolled-in_scale, scratches
- Splits: train, valid, test

The dataset is not included in this repository because it may be large
and is distributed separately. Obtain it from the source above and follow
its licensing and usage terms.

The recorded evaluation used the validation split. Test-set performance
must be evaluated separately before reporting it as a test result.
