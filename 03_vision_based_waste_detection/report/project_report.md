# Waste Detection — Project Report

## Objective
Demonstrate object detection on a waste-related image using YOLO11n.

## Method
A pretrained YOLO11n model was applied to the uploaded image with a confidence
threshold of 0.25.

## Recorded Results
- Image: gettyimages-918866504-612x612.jpg
- Detections: 6
- Inference time: 8.5907 seconds
- Device: 0

## Limitations
This is general-purpose object detection, not waste-specific material
classification. No custom training or ground-truth evaluation was performed.

## Conclusion
The pipeline demonstrates image inference and output visualization.
Waste-specific training is needed to reliably classify materials.
