# Dataset and Model Information

- Input: user-provided waste image
- Model: YOLO11n pretrained on COCO
- COCO source: https://cocodataset.org/
- This demonstration uses pretrained general-purpose object classes.
- It does not use a waste-specific training dataset.
- Dedicated paper, metal, cardboard, and waste-condition classification
  requires a suitable annotated dataset and custom training.
